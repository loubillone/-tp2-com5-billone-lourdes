# TP2 — Mi Portfolio Multipágina con React Router DOM

**Alumna:** Lourdes Billone
**Comisión:** COM5

## Descripción

Portfolio personal multipágina desarrollado con React y React Router DOM. Permite navegar entre distintas secciones mediante un menú lateral sin recargar la página. Incluye presentación personal, habilidades tecnológicas, proyectos realizados y formulario de contacto.

## Tecnologías utilizadas

- React 19
- Vite
- React Router DOM 7
- Bootstrap 5
- Font Awesome 6
- JavaScript + JSX
- CSS

## Instalación

```bash
npm install
```

## Ejecutar localmente

```bash
npm run dev
```

La aplicación estará disponible en `http://localhost:5173`.
